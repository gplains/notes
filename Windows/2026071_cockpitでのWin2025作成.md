
### windows server 2025 のイメージ新規作成

前提: /datastore/images 配下に windows 2025.iso と virtio-win.isoがあること
および、/datasotre/images 配下に wc2925.qcow2が作成できること

- Linux側でqcow2 イメージを作成
  cd /datastore/images
  qemu-img create -f qcow2 wc2025a.qcow2 40G
- Cockpitで新規作成
	- 接続: system
	- インストールタイプ:ローカルインストールメディア
	- インストールソース:/datastore/images/windows2025.iso
	- オペレーティングシステム: Windows Server 2025
	- ストレージ: images (qcow2の場所)
	- ボリューム: wc2025a.qcow2
	- メモリ:4 GB
- CockpitでISOを追加
  ディスクー＞ディスクの追加
	- ソース:カスタムパス
	- カスタムパス: /datastore/images/win2025.iso
	- デバイス:CD/DVD ディスク
	- カスタム>パス:sata
- さらにCockpitでISOを追加
  ディスクー＞ディスクの追加
	- ソース:カスタムパス
	- カスタムパス: /datastore/images/virtio-win-0.1.285.iso
	- デバイス: CD/DVD ディスク
	- カスタム>パス:sata
- ネットワークデバイスもせっかくなので変更
  モデルタイプ e1000e のところ > 編集
	- モデル：virtio
- 念のためブート順序も変更
	- disk(cdrom) を先頭に

- 言語設定を選択
	- インストールする言語:日本語
	- 時刻と通貨の形式:日本語
	- 次へ
- キーボード設定を選択
	- キーボードまたは入力形式:Microsoft IME
	- キーボードの種類: 
	  PC/AT 拡張キーボード 101/102 > 日本語キーボード 106/109キー
	- 次へ
- セットアップオプションの選択
	- Windows Server のインストール
	- I agree everything will be deleted including files, apps ,and settings
	- 次へ
- イメージの選択
	- Windows Server 2025 Standar Evaluation デスクトップエクスペリエンス
	- 次へ
- 適用される通知とライセンス事項
	- 同意する
- Windows Serverをインストールする場所の洗濯
	- ハードウェアが表示されていませんか？ドライバーを読み込み、ハードウェアにアクセスします
- Install driver to show hardware
	- 参照#1
	  e:\viostor\2k25\amd64 
	  Red Hat VirtIO SCSI Controller
	  -> インストール
	- 参照#2 (省略可)
	  Load Driver 押下
	  e:\NetKVM\2k25\amd64
	  Red Hat VirtIO Ethernet Adapter
	  -> インストール
	- 参照#3 (省略可)
	  Load Driver 押下
	  e:\vioserial\2k25\amd64
	  VirtIO Serial Driver
	- ディスク0の未割当領域 (40GB)
	- 次へ
- インストール準備完了
	- インストール

再起動後
- 設定のカスタマイズ
	- パスワード:
	- パスワードの確認入力
	- 完了
さらに再起動後
- E:\virtio-win-gt-x64.exe を実行
- E:¥guest-agent\qemu-ga-x86_64.msi を実行

Ubuntuのシェルを開いて
- virsh edit wc2025a
- 以下を追記
```
<channel type='unix'>
  <target type='virtio' name='org.qemu.guest_agent.0'/>
  <address type='virtio-serial' controller='0' bus='0' port='2'/>
</channel>

```

対象VMをシャットダウン＞起動してIPアドレスが表示されることを確認
